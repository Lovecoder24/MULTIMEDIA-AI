# AI Multimedia Generator

A web application that generates text, images, audio, and video using various AI APIs.

## Features
- Text generation using Replicate (Llama 2)
- Image generation using Stability AI
- Audio generation using ElevenLabs
- Video generation using Replicate

## Setup Instructions

1. Clone this repository
2. Create a `.env` file with your API keys:
   ```
   ELEVENLABS_API_KEY=your_key_here
   REPLICATE_API_KEY=your_key_here
   STABILITY_API_KEY=your_key_here
   ```
3. Install dependencies:
   ```
   pip install -r requirements.txt
   ```
4. Run the application:
   ```
   streamlit run app.py
   ```
